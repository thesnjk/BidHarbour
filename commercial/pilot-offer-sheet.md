# Supplier Desk — paid pilot offer sheet

**WARNING:** Pilot MSA/DPA stubs require **solicitor review** before use with real customer packs.  
See [`../security-and-legal/pilot-msa-stub.md`](../security-and-legal/pilot-msa-stub.md) and [`../security-and-legal/dpa-stub.md`](../security-and-legal/dpa-stub.md).

**As-of:** 9 November 2025 · Prices **ex VAT** · Proposed experiment (not validated market price)

## Offer

| Item | Spec |
|------|------|
| Product name in outreach | **Supplier Desk** |
| Duration | 4 weeks |
| Volume | Up to **3** inbound PQQ/SQ / document-request packs |
| Formats | PDF, Word, Excel questionnaires + supporting PDFs |
| Fee (mid anchor) | **£500** ex VAT (band £250–£750) |
| Delivery | Founder-operated concierge (library + checklist + human approve + export) |
| Prerequisite | Signed pilot terms + DPA; named Approver; MFA on accounts used |

## Included

- Evidence library intake for pilot scope  
- Requirement checklist per pack  
- Match to approved evidence / answers; **MISSING** where unsupported  
- Approver review gate before export  
- Pack export + simple activity log  
- Baseline vs pilot time measurement workshop (30 min)

## Excluded

- Public tender writing / discovery  
- Engineering estimates or pricing  
- Auto-submit to customer portals  
- Inventing certificates, policies, insurance or financial facts  
- Unlimited custom Word templating  
- Bid-win or qualification guarantees |

## Success metrics we measure

- Admin minutes per pack (baseline vs pilot)  
- Time to first complete draft  
- Missing-field rate (all mapped or marked missing)  
- Rework loops after approver review  
- Reviewer minutes; founder support minutes  
- Willingness to continue on subscription (**yes/no**) → [`../operations/pilot-continuation-log.md`](../operations/pilot-continuation-log.md)

Target threshold (management rule): median **≥90 minutes saved** per pack **or** stated value ≥£150/pack.

## After the pilot

Results review → offer setup (£300–£1,000 ex VAT band) + subscription (£99–£249/mo band hypotheses) **or** stop cleanly with data deletion/return per DPA.

**Scripts:** [`../operations/pilot-closeout-scripts.md`](../operations/pilot-closeout-scripts.md) (pack delivered → next pack → results review → yes/no → data return → optional testimonial).
