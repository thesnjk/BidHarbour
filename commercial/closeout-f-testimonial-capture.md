## Goal

Capture optional written testimonials from real pilots with explicit consent and attribution rules — separately from peer-intro referral ask **G**.

## When to ask

| Ready | Not ready |

| Continuation `yes` / clean `no` / or clear stop after **D** | Discovery-only soft decline (use post-interview referral instead) |
| Customer offered or clearly open to quoting | Pressure to invent social proof for GO |

## Rules

1. Store **only** customer-approved text — no invent, no polish that changes meaning.  
2. No win-rate, qualification, or bid-win claims in ask or stored quote.  
3. Keep **F** (testimonial) separate from **G** (peer intro).  
4. On **no** / no reply: leave blank; discard any drafted wording.  
5. Prefer anonymised label in this git template; keep named copy local if needed.
