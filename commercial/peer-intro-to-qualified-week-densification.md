## Goal

Densify a short week toward ≥1 **held** qualified discovery using NAAME / Hethel / GY network peer intros — without a new cold scrape and without treating booked-only or org-host chats as lead wins.

## Preconditions

| Check | Rule |
|-------|------|
| Network path | Peer-intro pack or observation kit follow-up — not Week-1 cold outreach alone |
| Week short | [`../research/qualified-discovery-week-tracker.md`](../research/qualified-discovery-week-tracker.md) shows &lt;1 held qualified so far |
| Lead ICP | Prefer AME / marine / fab peers with multi-customer PQQ/SQ — not anti-persona / reserve as wins |
| Not cold-50 | Do **not** scrape A51–A100; use warm intros / referrals / venue peers |

## Sequence

1. **Log intro ask** — Note venue (NAAME / Hethel / GY / LinkedIn) and script used from [`naame-hethel-gy-network-peer-intro-pack.md`](naame-hethel-gy-network-peer-intro-pack.md) or [`referral-ask-script.md`](referral-ask-script.md). Org hosts ≠ lead ICP wins.  
2. **CRM intake** — On warm yes: [`warm-intro-crm-intake.md`](warm-intro-crm-intake.md); stage Discovery; no invented contacts.  
3. **Book** — [`reply-booking-scripts.md`](reply-booking-scripts.md) (“yes / times”); grid slot Booked.  
4. **If they flake** — [`discovery-noshow-rebook-checklist.md`](discovery-noshow-rebook-checklist.md) (one rebook; densify warm/referral — still no new cold scrape).  
5. **On Held** — Mark grid `Held`; add week-tracker row; only then count toward Repeatable acquisition. Soft decline → one referral ask.  
6. **Week honesty** — Update [`../research/qualified-discovery-week-tracker.md`](../research/qualified-discovery-week-tracker.md); Pass week = ≥1 held qualified. Intro asks alone keep the week at 0 held.
