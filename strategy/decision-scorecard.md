# 23. Decision scorecard

These are **management decision rules**, not validated industry benchmarks.

## Thresholds

| Criterion | Threshold | Status (start) |
|-----------|-----------|----------------|
| Recurring problem evidence | ≥6/10 interviews in a niche reveal the same recurring problem | Not started |
| Existing-alternative inadequacy | Majority cannot name a tool that completes inbound multi-customer packs | Not started |
| Workflow evidence | ≥3 businesses provide observation / redacted pack evidence | Not started |
| Paid pilot conversion | 3 businesses pay for a defined pilot | Not started |
| Continuation | ≥2 continue paying after the pilot | Not started |
| Time / value delivered | Median ≥90 min saved per pack **or** stated value ≥£150/pack | Not started |
| Repeat usage | ≥2 packs processed per continuing customer in 60 days | Not started |
| Support effort | &lt;45 minutes support per customer per month after onboarding | Not started |
| Contribution margin | Positive contribution by customer #6 (ex founder draw sensitivity) | Not started |
| Repeatable acquisition | Documented channel producing ≥1 qualified discovery / week | Not started |
