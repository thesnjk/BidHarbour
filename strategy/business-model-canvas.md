# A. Business model canvas (one page)

**Product:** BidHarbour Supplier Desk  
**As-of:** 9 November 2025 — hypotheses until scorecard GO

| Block | Content |
|-------|---------|
| **Customer segments** | Norfolk engineering / fabrication / marine SMEs (5–75 FTE) facing multi-customer PQQ/SQ packs |
| **Value propositions** | Faster first approved draft; evidence-linked answers; missing/expired flags; exportable pack; audit trail — no invented compliance |
| **Channels** | Founder-led outreach via NAAME, Hethel, EEEZ/LinkedIn; referrals; no paid ads pre-validation |
| **Customer relationships** | Concierge pilot → assisted onboarding → light-touch support; high-trust for confidential packs |
| **Revenue streams** | Pilot fees; setup/import; monthly subscription (org-based); optional bounded overage — all **ex VAT** hypotheses |
| **Key resources** | Evidence library model; approval workflow; founder sales time; secure hosting; AI/OCR vendors under DPA |
| **Key activities** | Customer discovery; pilot delivery; library import; product iteration; security/legal hygiene |
| **Key partners** | OCR/LLM/hosting/Stripe subprocessors; local networks (access, not implied endorsement); accountant/solicitor |
| **Cost structure** | Founder time; hosting/AI usage; legal/insurance; travel; tools; later support hire |

**Unfair advantage (hypothesised):** Narrow supplier-side inbound pack job + strict human-approval evidence graph at SME price — **Proposed experiment**.
