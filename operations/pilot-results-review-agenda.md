## Goal

Close the pilot loop with real **Time/value** contrast and a clear path to **written continuation** (scorecard Continuations) — or a clean stop (**E**).

## Preconditions

- [ ] Pilot window ending **or** packs completed (max 3)  
- [ ] Script **C** sent / slot booked  
- [ ] Kickoff baseline captured (or honest gap noted) on local worksheet  
- [ ] Live metrics rows exist for packs completed (`mode` live only — exclude dry-runs)  
- [ ] Approver / export outcomes known per pack (no invented manifests)

## Pre-read (local / encrypted — not git Actuals)

1. Pull live CSV rows into [`minutes-saved-contrast-rollup.md`](minutes-saved-contrast-rollup.md) **locally**.  
2. Open kickoff [`baseline-minutes-worksheet.md`](baseline-minutes-worksheet.md) contrast ritual.  
3. Optional: interview time-study for the same firm if completed.  
4. Note MISSING / rework / Approver friction from pack notes (redacted).  
5. Have offer sheet bands ready as **hypotheses** only.

## ≈30 min timed agenda

| Min | Topic | Lead with | Do not |
|-----|-------|-----------|--------|
| 0–3 | Open | Thank; purpose = learning + next-step clarity | Pitch win rates |
| 3–12 | Minutes contrast | Baseline vs live `minutes_to_first_draft` / support / rework via rollup | Use DRY-008 or any dry_run as proof |
| 12–18 | Gaps & gates | MISSING counts, rework loops, Approver/export experience | Invent fills or claim export always easy |
| 18–24 | What worked / friction | Checklist match, encrypted path, buyer-specific packs (FO7) | Promise SaaS features pre-GO |
| 24–28 | Continuation hypotheses | Setup + subscription bands on offer sheet — **Advice required** / solicitor terms | Bind customer to uncleared MSA |
| 28–30 | Next steps | Agree: written **yes/no** via **D** same day; or stop path **E** | Leave continuation verbal-only |

## Continuation bridge (C → D)

```text
Results review (this agenda)
    → same day: send script D (written yes/no)
    → continuation log: pending
    → on reply: yes | no
         ├─ yes → commercial outline + solicitor-cleared continuation terms (no packs until cleared)
         └─ no  → script E (data return) · optional G referral if rapport
                    (fill [`../commercial/pilot-referral-evidence-packet.md`](../commercial/pilot-referral-evidence-packet.md) locally first)
```

| Step | Action |
|------|--------|
| 1 | End call with explicit ask for written **yes** or **no** |
| 2 | Send [`pilot-closeout-scripts.md`](pilot-closeout-scripts.md) §D same day |
| 3 | Add [`pilot-continuation-log.md`](pilot-continuation-log.md) row `pending` (real pilots only) |
| 4 | On reply: set `yes`/`no`; CRM stage per [`../commercial/crm-stage-scripts.md`](../commercial/crm-stage-scripts.md) |
| 5 | Scorecard Continuations / Time/value Actuals **only** from real rollup + real `yes` rows |
| 6 | Before optional **G**: fill [`../commercial/pilot-referral-evidence-packet.md`](../commercial/pilot-referral-evidence-packet.md) locally (anonymised; no invent) → [`../commercial/referral-ask-script.md`](../commercial/referral-ask-script.md) |

## Founder checklist

- [ ] Pre-read rollup completed locally (live rows only)  
- [ ] Meeting held; no win-rate claims  
- [ ] Script **D** sent same day  
- [ ] Continuation log updated (`pending` → decision)  
- [ ] On `no`/timeout: script **E** diaried  
- [ ] On `yes`: legal/commercial path — still no packs until cleared  
- [ ] Optional **F** / **G** only after rapport and not during refund friction  
- [ ] Before **G**: local [`../commercial/pilot-referral-evidence-packet.md`](../commercial/pilot-referral-evidence-packet.md) filled from live rollup  
- [ ] Scorecard cells left blank until real evidence  

## Stop rules

- Never invent minutes-saved or continuation Actuals.  
- Never treat dry-runs as Time/value proof.  
- Never process further confidential packs on verbal “yes” alone.  
- Never claim bid wins or qualification outcomes.  
- Never commit filled customer rollups or decision emails to git.
