## Ask solicitor to return

- [ ] Pilot MSA suitable for Norfolk SME pilots  
- [ ] DPA (controller/processor; subprocessors; retention/deletion; international transfers)

- [ ] Refund/cancellation language replacing our draft intent  
- [ ] Anything that **blocks** processing real packs  

## Founder after send

- [ ] Log date sent + firm name (private notes — not in git if sensitive)  
- [ ] Do **not** start paid pilots with real packs until cleared drafts exist  
- [ ] Concierge discovery interviews without uploading third-party customer packs may continue  
- [ ] Customer discovery→pilot offer email ([`../commercial/pilot-offer-email.md`](../commercial/pilot-offer-email.md)) is **separate** from this solicitor cover — still no packs until cleared  
- [ ] When drafts return: run [`solicitor-return-intake-checklist.md`](solicitor-return-intake-checklist.md) (vault MSA/DPA; PASS/FAIL; Script A unlock)
