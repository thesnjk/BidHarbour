# Workflow observation checklist

**Goal:** Watch (or reconstruct with artefacts) a real pack — not a demo pitch.

## Before

- [ ] Consent for observation / screenshare (verbal **or** [`observation-consent-email.md`](observation-consent-email.md))  
- [ ] Agree redaction rules  
- [ ] Confirm this is a recent or in-progress pack  

## During — capture

| Checkpoint | Observed | Notes |
|------------|----------|-------|
| Channel received (email/portal) | | |
| File types and page count | | |
| Number of distinct requirements (approx) | | |
| Where evidence lived (paths/tools) | | |
| People involved + handoffs | | |
| Time on each major step (stopwatch or estimate) | | |
| Missing items encountered | | |
| Expired items encountered | | |
| Conflicts / duplicate versions | | |
| Approval step present? Who? | | |
| Submission method | | |
| Archival location after submit | | |

## Failure / friction moments

- [ ] List each friction with minute mark / step  
- [ ] Note workaround used  

## After

- [ ] Confirm estimated total minutes with participant  
- [ ] Ask what they would refuse to upload to a vendor  
- [ ] Log negative finding  
- [ ] Add `OBS-YYYYMMDD-##` row in [`observation-session-log.md`](observation-session-log.md)  
- [ ] File note using `recording-template.md` — **do not commit PII**
