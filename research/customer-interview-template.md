# Customer interview template (printable pack)

Use together:

1. Consent + questions → [`interview-guide.md`](interview-guide.md)  
2. Capture sheet → [`recording-template.md`](recording-template.md)  
3. If observing a live pack → [`observation-checklist.md`](observation-checklist.md)  
4. Log disconfirming evidence → [`negative-findings.md`](negative-findings.md)  
5. Update counts → [`validation-scorecard.md`](validation-scorecard.md) / `validation-scorecard.xlsx`

**Rule:** Recent behaviour and actual documents. Hypothetical enthusiasm is not purchase intent.
